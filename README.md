# Mirage 🛡️

**Mirage** — это высокопроизводительный, криптографически стойкий и устойчивый к системам глубокого анализа трафика (DPI) прокси-туннель. 

Проект разработан для обхода современных систем интернет-цензуры, включая Великий Китайский Файрвол (GFW) и системы ТСПУ. Mirage маскирует свой трафик под обычные подключения к популярным сайтам (Reality-маскировка) и обеспечивает совершенную прямую секретность (Perfect Forward Secrecy) за счет протокола **Noise**.

## Ключевые возможности

*   **Маскировка Reality**: Сервер выдает себя за настоящий сайт (например, `www.google.com:443`). Любые попытки активного сканирования (Active Probing) со стороны цензоров будут прозрачно перенаправляться на реальный сайт. Цензор увидит лишь обычный TLS 1.3 сайт.
*   **Современная криптография (Noise Protocol Framework)**: Использование профиля `Noise_XXpsk3_25519_ChaChaPoly_BLAKE2s`. Это обеспечивает шифрование, аутентификацию обеих сторон и скрытие метаданных.
*   **Мультиплексирование (yamux)**: Множество логических потоков внутри одного зашифрованного туннеля для максимальной скорости и минимальной задержки.
*   **Поддержка QUIC и TCP**: Возможность работы поверх UDP (QUIC) для обхода TCP-блокировок и TCP-троттлинга, либо поверх TCP для стабильности.
*   **TCP Фрагментация (Anti-DPI)**: Искусственная нарезка стартовых пакетов (`ClientHello`) для обхода DPI-систем, анализирующих сигнатуры.
*   **Поддержка плагинов SIP003**: Mirage может работать как транспортный плагин для любых клиентов и серверов **Shadowsocks** (например, **v2rayN**, **shadowsocks-rust**).
*   **Ротация ключей без даунтайма**: Сервер поддерживает чтение ключей из файла и их горячую перезагрузку по сигналу `SIGHUP`.
*   **Встроенная статистика**: HTTP API для мониторинга активных подключений и проходящего трафика.

## 🚀 Быстрая установка (Сервер)

На вашем Linux-сервере выполните всего одну команду:

```bash
bash <(curl -sL https://raw.githubusercontent.com/Onikore/mirage/main/install.sh)
```

Скрипт автоматически скачает компилятор Go (если нужно), соберет бинарный файл, сгенерирует ключи, создаст systemd-сервис и запустит его. После установки скрипт выведет ваши ключи для настройки клиента.

---

## 🛠 Настройка (Ручная установка)

### 1. Компиляция
Убедитесь, что у вас установлен Go 1.20+.
```bash
git clone https://github.com/Onikore/mirage.git
cd mirage
CGO_ENABLED=0 go build -o mirage ./cmd/mirage
```

### 2. Генерация ключей
```bash
./mirage keygen
```
Сохраните полученные `server_priv`, `server_pub` и `psk`.

### 3. Запуск сервера
```bash
./mirage server -listen :8443 \
    -priv <ВАШ_SERVER_PRIV> \
    -psk <ВАШ_PSK> \
    -dest www.google.com:443 \
    -quic
```
*(Для TCP-режима просто уберите флаг `-quic`)*

### 4. Запуск клиента
```bash
./mirage client -listen 127.0.0.1:1080 \
    -server <IP_СЕРВЕРА>:8443 \
    -pub <ВАШ_SERVER_PUB> \
    -psk <ВАШ_PSK> \
    -sni www.google.com \
    -quic \
    -fragment
```

Теперь вы можете использовать `127.0.0.1:1080` как стандартный SOCKS5 прокси в вашем браузере или Telegram.

## 🔌 Интеграция с Shadowsocks (SIP003 Plugin)

Mirage поддерживает работу в режиме плагина SIP003. Это позволяет использовать его в связке с клиентами типа **v2rayN** для Windows или **shadowsocks-android**.

### Настройка в v2rayN:
1. Создайте профиль сервера Shadowsocks.
2. IP и Порт укажите те же, что настроены на сервере Mirage (например, `8443`).
3. Метод шифрования и пароль: любые (Shadowsocks инкапсулируется внутрь Mirage).
4. **Plugin (Плагин)**: `mirage` *(Поместите mirage.exe в ту же папку, где находится ядро v2ray)*
5. **Plugin Options (Опции плагина)**: 
   ```
   pub=ВАШ_SERVER_PUB;psk=ВАШ_PSK;sni=www.google.com;quic;fragment
   ```

### Настройка сервера Shadowsocks:
Запустите `shadowsocks-rust` с передачей нашего бинарника в качестве плагина:
```bash
ssserver -s "0.0.0.0:8443" -m "aes-256-gcm" -k "password" \
    --plugin "/usr/local/bin/mirage" \
    --plugin-opts "server;priv=ВАШ_SERVER_PRIV;psk=ВАШ_PSK;dest=www.google.com:443;quic"
```

## 📊 Мониторинг и API Статистики

При запуске сервера или клиента с флагом `-api 127.0.0.1:8080`, вы можете получать метрики в реальном времени:

```bash
curl -s http://127.0.0.1:8080/stats
```
Пример ответа:
```json
{
  "active_connections": 12,
  "bytes_down": 104857600,
  "bytes_up": 5242880,
  "probes_rejected": 14
}
```
