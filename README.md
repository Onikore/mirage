# Mirage 🛡️

**Mirage** — это высокопроизводительный, криптографически стойкий и устойчивый к системам глубокого анализа трафика (DPI) прокси-туннель. 

Проект разработан для обхода современных систем интернет-цензуры, включая Великий Китайский Файрвол (GFW) и системы ТСПУ. Mirage маскирует свой трафик под обычные подключения к популярным сайтам (Reality-маскировка) и обеспечивает совершенную прямую секретность (Perfect Forward Secrecy) за счет протокола **Noise**.

## ⚡ Быстрый старт (Linux Server)

Выполните одну команду от имени `root`:

```bash
bash <(curl -sL https://raw.githubusercontent.com/Onikore/mirage/master/install.sh)
```
Скрипт установит Go, соберет проект, сгенерирует ключи и запустит `mirage.service`.
