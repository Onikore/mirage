# MIRAGE — скелет протокола обхода блокировок

Минимальный работающий PoC ядра: аутентифицированное рукопожатие X25519,
AEAD-фреймы, SOCKS5-вход, анти-зонд-fallback. Только stdlib Go, без зависимостей.

Это **скелет для проверки идеи**, не боевой инструмент. Что намеренно упрощено —
см. раздел «Что дальше».

## Сборка

```
go build -o mirage .
```

## Запуск (локальный тест)

```
# 1. ключи
./mirage keygen
#   server_priv: <PRIV>
#   server_pub:  <PUB>
#   psk:         <PSK>

# 2. сервер (dest — реальный сайт, куда уводятся зонды)
./mirage server -listen :8443 -priv <PRIV> -psk <PSK> -dest example.com:443

# 3. клиент (локальный SOCKS5)
./mirage client -listen 127.0.0.1:1080 -server SERVER_IP:8443 -pub <PUB> -psk <PSK>

# 4. направь браузер/curl в SOCKS5
curl --socks5-hostname 127.0.0.1:1080 https://blocked.example/
```

## Что проверено (loopback)

1. Легитимный трафик проходит через туннель.
2. Клиент с неверным PSK — рукопожатие отвергается, туннель не строится.
3. Сырой HTTP-зонд на порт сервера прозрачно проксируется на `dest` —
   сервер неотличим от обычного веб-сервера.

## Как устроено

```
Браузер ──SOCKS5──> client ──[X25519 handshake + AEAD frames]──> server ──> target
                                                                    │
                                                        (плохой auth) └──> dest (реальный сайт)
```

- `crypto.go`    — X25519 (crypto/ecdh), HKDF-SHA256, AES-256-GCM
- `handshake.go` — 2-сообщенийное рукопожатие: es+ee (forward secrecy), PSK (auth клиента), анти-зонд
- `frame.go`     — потоковый AEAD-канал (io.ReadWriteCloser), хук для shaping
- `addr.go`      — кодирование целевого адреса
- `socks.go`     — SOCKS5 вход
- `main.go`      — keygen / server / client

## Что дальше (по приоритету)

1. **uTLS-камуфляж + Reality-стиль.** Сейчас первый байт — «голый» X25519,
   энтропийный детектор его увидит. Оборачивать рукопожатие в настоящий
   TLS 1.3 ClientHello (JA4 браузера), auth смаглить в key_share. Это главное.
2. **QUIC/HTTP3-план.** quic-go, датаграммы для UDP, стримы для TCP,
   connection migration. Salamander-обфускация QUIC-заголовка.
3. **Мультиплекс.** Сейчас одно TCP-соединение на один запрос. Добавить
   stream_id в кадры, гонять все стримы по одной сессии.
4. **Chameleon shaping.** PADDING-кадры + подгонка размеров/таймингов под
   профиль реального HTTP/3-трафика. Хук уже размечен в frame.go.
5. **Anti-replay.** LRU/bloom-кэш auth-токенов в пределах временного окна.
6. **Крипто-апгрейд.** Заменить самодельное рукопожатие на полноценный
   Noise_IKpsk2 (flynn/noise или snow). Педагогический вариант не трогать в бою.

## Дисклеймер

Не боевой код: нет ротации ключей, нет rate-limit, нет защиты от timing/replay,
рукопожатие упрощённое. Для реального использования — форкать sing-box/xray и
переиспользовать их обкатанные транспорт и Reality.
