# Использование Mirage

В этом разделе описаны все доступные аргументы командной строки и сценарии использования.

## Команды

`./mirage [команда] [аргументы]`

Доступные команды:
- `server` — Запуск в режиме сервера.
- `client` — Запуск в режиме клиента (SOCKS5 прокси).
- `keygen` — Генерация новой связки ключей.

---

## 🖥 Режим Сервера (`server`)

### Флаги
- `-listen <адрес>`: Локальный IP и порт, на котором сервер будет принимать соединения. (По умолчанию `:8443`).
- `-priv <hex>`: Приватный ключ сервера (генерируется через `keygen`).
- `-psk <hex>`: Pre-Shared Key (генерируется через `keygen`).
- `-dest <хост:порт>`: Адрес реального сайта для Reality-маскировки. Именно этот сайт увидят цензоры при попытке просканировать ваш сервер. Желательно указывать крупный сайт (например, `www.google.com:443` или `www.microsoft.com:443`).
- `-quic`: Использовать протокол QUIC (UDP) вместо TCP.
- `-padding`: Включить периодическую отправку мусорных пакетов случайной длины (усложняет анализ таймингов).
- `-api <ip:port>`: Запустить локальный HTTP-сервер для отдачи статистики.
- `-priv-file <путь>`: Путь к файлу с приватными ключами (один hex-ключ на строку). Заменяет флаг `-priv`.
- `-psk-file <путь>`: Путь к файлу с PSK (один hex-ключ на строку). Заменяет флаг `-psk`.

### Ротация ключей без даунтайма
Если вы используете `-priv-file` и `-psk-file`, вы можете менять ключи "на лету", не разрывая текущие соединения.
1. Добавьте новый ключ новой строкой в файл (оставив там и старый).
2. Отправьте процессу сигнал: `kill -SIGHUP <pid_mirage>`.
3. Сервер перечитает файл и начнет принимать соединения по обоим ключам.
4. Раздайте новый ключ клиентам. Когда все перейдут, удалите старый ключ из файла и снова отправьте `SIGHUP`.

## 💻 Режим Клиента (`client`)

### Флаги
- `-listen <адрес>`: Локальный адрес для запуска SOCKS5-прокси (По умолчанию `127.0.0.1:1080`).
- `-server <ip:порт>`: Адрес вашего сервера Mirage.
- `-pub <hex>`: Публичный ключ сервера.
- `-psk <hex>`: Pre-Shared Key.
- `-sni <хост>`: Доменное имя для обфускации (Server Name Indication). Должно совпадать с доменом сайта, указанного в `-dest` на сервере.
- `-quic`: Использовать протокол QUIC (сервер также должен быть запущен с этим флагом).
- `-padding`: Включить мусорный трафик.
- `-fragment`: **(Только для TCP)** Агрессивно нарезать первые пакеты (ClientHello) на кусочки по 10 байт. Спасает, если DPI блокирует подключения по сигнатуре.
- `-api <ip:port>`: Запустить локальный HTTP-сервер для отдачи статистики.

## 📊 API Статистики

Если запустить клиент или сервер с параметром `-api 127.0.0.1:8080`, вы сможете обращаться к нему для получения телеметрии.

**Запрос:**
```bash
curl -s http://127.0.0.1:8080/stats
```

**Ответ:**
```json
{
  "active_connections": 12,
  "bytes_down": 104857600,
  "bytes_up": 5242880,
  "probes_rejected": 14
}
```

**Описание полей:**
- `active_connections`: Количество текущих живых сессий (Noise-туннелей).
- `bytes_down`: Количество байт, скачанных клиентами (или отправленных сервером).
- `bytes_up`: Количество байт, отправленных клиентами (или полученных сервером).
- `probes_rejected` (Только сервер): Сколько раз сервер обнаружил "сканирование" и перенаправил чужой трафик на `-dest` сайт.
