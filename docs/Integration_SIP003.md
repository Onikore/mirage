# Интеграция с Shadowsocks (SIP003)

Mirage поддерживает спецификацию **SIP003**, что позволяет ему работать как транспортный "плагин" (Plugin) для любых совместимых Shadowsocks-клиентов и серверов. 

Это позволяет обойтись без "голого" SOCKS5 и пользоваться привычными удобными программами вроде **v2rayN**, **v2rayNG**, **Shadowrocket**, **Clash** и т.д.

## Архитектура работы в режиме плагина

Когда Shadowsocks-клиент (например, v2rayN) вызывает Mirage, он передает ему системные переменные окружения (`SS_REMOTE_HOST`, `SS_PLUGIN_OPTIONS` и т.д.). Mirage автоматически замечает это, отключает свой внутренний SOCKS5-парсер и превращается в **прозрачный туннель**. 

Весь трафик (TCP) шифруется и пробрасывается "как есть" на Mirage-сервер, который затем отдает его локальному серверу Shadowsocks.

## 1. Настройка на стороне Сервера

Вам потребуется установить на сервер классический Shadowsocks. Рекомендуется использовать современный `shadowsocks-rust`.

Предположим, бинарник `mirage` лежит в `/usr/local/bin/mirage`.

Запуск Shadowsocks-сервера:
```bash
ssserver -s "0.0.0.0:8443" \
         -m "aes-256-gcm" \
         -k "my_secret_ss_password" \
         --plugin "/usr/local/bin/mirage" \
         --plugin-opts "server;priv=ВАШ_SERVER_PRIV;psk=ВАШ_PSK;dest=www.google.com:443;quic"
```

**Разбор `plugin-opts`:**
- `server` — указывает Mirage запуститься в режиме сервера.
- `priv=` и `psk=` — ваши криптографические ключи.
- `dest=` — сайт для Reality-маскировки (fallback).
- `quic` — (Опционально) использовать QUIC.

*Примечание: Вы также можете использовать systemd или config.json для ssserver.*

## 2. Настройка на стороне Клиента (На примере v2rayN для Windows)

1. Скачайте [v2rayN](https://github.com/2dust/v2rayN).
2. Положите файл `mirage.exe` в ту же папку, где лежит файл `v2rayN.exe` (или в папку `bin`, если она есть).
3. Откройте v2rayN и добавьте новый сервер: `Servers` -> `Add [Shadowsocks] server`.
4. Заполните поля:
   - **Address**: IP вашего сервера (на котором запущен `ssserver`).
   - **Port**: Порт вашего сервера (`8443`).
   - **Password**: Пароль от Shadowsocks (`my_secret_ss_password`).
   - **Encryption**: Метод шифрования (`aes-256-gcm`).
   - **Plugin**: Впишите слово `mirage`.
   - **Plugin Options**: Впишите параметры для плагина (через точку с запятой). Пример:
     `pub=ВАШ_SERVER_PUB;psk=ВАШ_PSK;sni=www.google.com;quic;fragment`

**Разбор `Plugin Options` для клиента:**
- `pub=` и `psk=` — ваши криптографические ключи.
- `sni=` — сайт-маскировка (должен совпадать с `dest` на сервере).
- `quic` — (Опционально) использовать QUIC.
- `fragment` — (Опционально) включить TCP-фрагментацию для обхода DPI.
- `padding` — (Опционально) включить зашумление трафика.

После сохранения профиля просто выберите его и нажмите "Подключиться". v2rayN сам запустит `mirage.exe` в фоне и направит через него весь ваш трафик!
